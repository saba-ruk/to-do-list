# ✅ To-Do List Web Application

## Overview

**To-Do List Web Application** is a simple and interactive task management system developed as a **BCA Second Year Mini Project**. The application allows users to create, organize, and manage their daily tasks efficiently through a clean and user-friendly interface.

The project was designed to strengthen the understanding of front-end web development concepts such as HTML, CSS, and JavaScript by implementing dynamic task management functionality.

## Project Structure

```text
to-do-list-main/
│
├── to_do_list.html      # Main application page
├── style.css            # Styling file
├── script.js            # Application logic
├── circle.png           # Task icon
├── tick.png             # Completed task icon
├── todolist.png         # Application image
└── README.md

## How to Run

### Step 1

Download or clone the repository:

```bash
git clone https://github.com/your-username/to-do-list.git
```

or simply download and extract the ZIP file.

### Step 2

Open the project folder.

### Step 3

Double-click or open the following file in your browser:

```text
to_do_list.html
```

The application will launch and you can start managing your daily tasks.
